## Мета

Навчитися створювати контрольовані форми в React і виносити повторювану логіку в користувацькі хуки.

## Опис

Покедекс — вебзастосунок на React, який отримує інформацію про покемонів із [PokéAPI](https://pokeapi.co/). Форма фільтрів дає змогу шукати покемонів за назвою, обирати тип, сортування та кількість результатів.

## Можливості

- Пошук покемонів за назвою.
- Фільтрація за типом.
- Сортування за ім’ям або атакою.
- Вибір кількості результатів: 10, 20 або 50.
- Оновлення таблиці та статистичних карток відповідно до вибірки.
- Скидання фільтрів до початкових значень.
- Відображення станів завантаження, помилки та порожнього результату.
- Повторне завантаження даних після помилки.

## Контрольована форма

Значення полів зберігаються у стані React. Кожне поле отримує поточне значення через `value`, а зміни передаються через `onChange`.

## Власні хуки

- `useDebounce` (`src/hooks/useDebounce.js`) затримує застосування змін форми на 400 мс.
- `useFetch` (`src/hooks/useFetch.js`) виконує запит і керує станами `data`, `loading` та `error`. Також підтримує повторне завантаження.
- `usePokemonData` (`src/hooks/usePokemonData.js`) використовує `useFetch` для завантаження покемонів і формує дані для карток статистики.

## Запуск проєкту

Потрібно встановити [Node.js](https://nodejs.org/).

У терміналі перейдіть до папки `lab3` та встановіть залежності:

```powershell
npm.cmd install
```

Запустіть сервер розробки:

```powershell
npm.cmd run dev
```

Відкрийте адресу, яку покаже термінал — зазвичай <http://localhost:5173/>.
