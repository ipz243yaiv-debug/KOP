# Покедекс

Навчальний дашборд на React і Vite для лабораторної роботи з компонентно-орієнтованого програмування. У проєкті використовуються локальні мокові дані; запитів до PokeAPI немає.

## Функціональність

- Три перевикористані KPI-картки зі статистикою.
- Степпер для вибору покоління Pokémon від 1 до 9.
- Перемикач світлої та темної теми.
- Таблиця з Pokémon і фільтром за типом.
- Адаптивне оформлення на чистому CSS.

## Запуск

Потрібен встановлений Node.js. У терміналі з кореневої папки проєкту виконайте:

```bash
npm install
npm run dev
```

Відкрийте адресу, яку надрукує Vite (зазвичай `http://localhost:5173/`).

Щоб зібрати production-версію:

```bash
npm run build
```

Щоб локально переглянути зібрану версію:

```bash
npm run preview
```

## Структура проєкту

```text
src/
├── components/              # Віджети та стилі кожного віджета
├── data/
│   └── mockPokemonData.js    # Мокові KPI, Pokémon і типи
├── layout/
│   └── DashboardLayout.jsx  # Спільний каркас дашборду
├── App.css                  # Стилі розкладки сторінки
├── App.jsx                  # Стан теми та передавання даних у layout
├── index.css                # Глобальні стилі й змінні теми
└── main.jsx                 # Точка входу React
```
